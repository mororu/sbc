### Architecture delta

- **Lint and cycles:** lint-enforced layers hold, with 0 cycles, no db or env violations, and only type imports from client code into `src/lib/server`.
- **New module kinds the spine does not list:**
  - seven admin view models (`src/lib/server/*-view.ts`);
  - route-shell helpers in `src/lib/server` that import `@sveltejs/kit` (`reply-action.ts:9`, `call-action.ts:13`);
  - four `src/lib/*-outcome.ts` client helpers.
  - **Disposition:** reconcile in the spine (S1, carried over).
- **Admin reads reach the guest routes.** The guest routes share the `queries/index.ts` barrel with `admin.ts`, `impact.ts` and `block.ts`, and no lint rule keeps admin reads and view models out of `routes/(guest)`. Today no guest route imports them (grep). **Disposition:** C6, together with B4.
- **Rules computed outside the domain (AD-1):**
  - the "in season" predicate is written in 6 places, 3 of them outside the domain (`admin-day-view.ts:237, 256`, `settings-view.ts:148`);
  - "current or next season" in 2 places;
  - season overlap only in the command;
  - "started" (`start ≤ now`) in 7 places;
  - the pre-heat stale token is built in the query layer (`queries/impact.ts:141`), not by `impactToken`.
  - **Disposition:** C7.

### Duplication map

- **`queries/admin.ts`** has 415 lines, from the sign-in hash to old codes.

- **Disposition:** C7, split by concern.

### Pattern divergence

- **HTTP mapping of the same codes:**
  - `not_found` is 410 for deletes, 409 `already_done` for reply and call, and 503 for seasons;
  - `past` is 409 for deletes and blocks, `already_done` for calls, and 400 or 503 for seasons.

  Each is decided per story, but there is no epic-wide rule. Accept for now, and note it in S1.
- **Stale tokens:** three shapes (`impactToken`, pre-heat JSON, canonical notice). Accept, but C7 moves the pre-heat token into the domain.
- **View loader signatures differ:** an options object, positional arguments, filter-first, or no `db` at all. Queries disagree on argument order. Accept; folded into C7.
- **Result codes outside the spine's convention:** `signIn` adds `rate_limited`, and `changeSettings` adds `field`. Reconcile the convention in S1.
- **A stale lint comment:** the block-level disable in `(portal)/+layout.svelte:39` still says "later stories add the remaining routes", but only Auswertung (Epic 6) is left. Fix with C5.
