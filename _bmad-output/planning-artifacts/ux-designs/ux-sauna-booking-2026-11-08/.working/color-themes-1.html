Sauna Luegisee — fünf warme Farbwelten

Warm palettes in five registers, each in light and dark mode. Hot = solid border + flame icon + label. Cold start = dashed border + snowflake icon + label, in a cool counter-hue, so it never relies on colour alone. Belegt = hatched + strikethrough + lock icon.

The number beside each chip is the contrast ratio against the card surface (focus ring: against the background). All text roles reach WCAG AA 4.5:1 or better. The ring around 19:00 shows focus.
